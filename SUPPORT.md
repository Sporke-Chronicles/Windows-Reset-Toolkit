# Support

This is a community project and is not an official Microsoft support channel.

Before opening an issue:

1. Read `docs/troubleshooting.md` and `docs/limitations.md`.
2. Run the relevant preflight/detection path first.
3. Collect sanitized logs, `reagentc /info`, partition layout, Windows build, BitLocker status, and storage-controller/driver details.
4. State whether the problem occurred in the readiness workflow, ConfigMgr workflow, or Intune carve-out reset workflow.

For Microsoft product support questions involving Intune, Windows, BitLocker, WinRE, or ConfigMgr themselves, use the appropriate Microsoft support route in parallel where necessary.
